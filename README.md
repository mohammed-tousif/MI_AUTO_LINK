# M.I. Auto Links

A modern, responsive website for **M.I. Auto Links**, a vehicle buying and selling business based in Hubli, Karnataka. The site presents the dealership's 4, 6, and 10-wheeler offerings alongside financing, insurance, and RTO support services.

## Live Website

**[Visit M.I. Auto Links](https://mi-auto-link.vercel.app)**

The production website is hosted on Vercel and connected to the repository's `main` branch.

## Highlights

- Premium automotive landing-page design
- Dedicated sections for 4, 6, and 10 wheelers
- Responsive layouts for desktop, tablet, and mobile
- Scroll-reveal, marquee, counter, and hover animations
- Custom-generated automotive hero artwork
- Consistent inline SVG icon system
- Direct phone and WhatsApp enquiry actions
- RTO transfer, vehicle finance, and insurance information
- Reduced-motion accessibility support

## Technology

The website is intentionally lightweight and requires no build process:

- HTML5
- Modern CSS
- Vanilla JavaScript
- Inline SVG icons
- Google Fonts
- Vercel hosting
